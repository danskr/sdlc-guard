# SDLC-Guard RAG Import Corpus

This directory contains the rendered Markdown representation of the 37 demo SDLC artifacts that SDLC-Guard uploads to RAGFlow. Each document carries artifact metadata, relationships, specification content, and—where a `source_path` exists—the connected source-code or automated-test implementation.

The authoritative source remains `artifacts/`; these Markdown files are regenerated from that corpus so you can inspect exactly what semantic evidence is sent to RAGFlow.
