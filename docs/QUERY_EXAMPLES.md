# SDLC-Guard Query Examples

- Do you see any inconsistencies in the current scope of the project?
- Are there any gaps in the current scope of the project?
- What are the missing pieces in the project?
- Are there any approved functionalities not covered by test implementation?
- Are there any functionalities that are not implemented at all and have no source-code counterpart?
- Is there code that has no corresponding approved requirement?
- Which NFRs have no verification?
- What would be affected if wallet payment were removed?
- Is checkout ready for release?
- Explain the wallet implementation mismatch and cite the related artifacts.
- Does the implementation satisfy the payment idempotency requirement?
- What is the traceability path from the partial refund story to implementation and tests?
